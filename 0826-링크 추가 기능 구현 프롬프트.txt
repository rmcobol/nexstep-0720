<<링크 추가 기능 구현>>

1.

링크 추가 기능을 구현해 줘.

- 먼저 특정 링크의 오픈 그래프 정보를 추출하는 API부터 구현
- 새 링크 페이지에서 저장 버튼을 누르면 링크 저장해
- 저장 시 오픈 그래프 API로 제목, 설명, 썸네일, 링크 주소를 함께 수집해서 저장해 줘
- 새롭게 보관되는 링크 카드에 썸네일도 함께 표시해줘

===>링크 추가 기능 구현 커밋

3.
링크 삭제 기능을 구현해 줘.

- 삭제 버튼은 링크 카드에 마우스를 올리면 우측 상단에 휴지통 모양으로 나타나게 해줘
- 삭제 버튼 클릭 시 확인을 구하는 모달을 열어줘

4.

===>링크 삭제 구현 커밋


5.
링크 수정 기능을 만들어 줘

- 수정 버튼은 링크 카드에 마우스를 올렸을 때 우측 상단에 연필 모양의 아이콘으로 나타나게 해줘
- 수정 버튼 클릭시 링크 정보를 수정할 수 있는 모달 창을 열어줘
- 모달 창 안에는 링크의 폴더, 제목, 설명만 수정할 수 있도록 해줘
