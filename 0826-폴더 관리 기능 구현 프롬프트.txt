<<폴더 관리 기능 구현 프롬프트>>

1.
폴더 추가 기능을 만들어 줘.

- 새 폴더 버튼은 헤더 컴포넌트의 새 링크 버튼 좌측에 배치
- 클릭 시 화면 가운데에 모달이 열리도록 구현
- 모달 안에는 폴더 이름 입력 인풋, 취소 버튼, 저장 버튼 배치
- 저장 시 새 폴더가 좌측 사이드바에 즉시 추가될 것

2. 새폴더를 눌렸을때 모달이 가운데로 실행이 안되면

새폴더를 클릭하면 모달이 페이지 가운데로 실행이 되게
만들어 줘

3.
==>폴더 관리 추가 커밋

4.
 폴더 삭제 기능을 구현해 줘.

- 삭제 버튼은 좌측 사이드바의 폴더 이름에 마우스를 올렸을 때 우측에 노출
- 휴지통 모양 아이콘 사용
- 클릭 시 사용자 실수를 막기 위해 모달로 한 번 더 확인

5.
==>폴더 관리 삭제 커밋

6.
폴더 수정 기능을 구현해 줘.

- 수정 버튼은 사이드바 폴더 이름에 마우스를 올렸을 때 우측에 노출
- 연필 모양 아이콘 사용
- 클릭 시 폴더 이름을 수정하는 모달이 열리도록 구현

=====>폴더 관리 수정 커밋
