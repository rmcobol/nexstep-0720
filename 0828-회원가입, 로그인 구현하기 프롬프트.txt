
<<<회원가입, 로그인 구현하기 프롬프트>>

1. 로그인·회원가입 페이지 UI 구현

로그인, 회원가입 페이지의 UI를 구현해줘.

#로그인 페이지

- 로고 텍스트, 이메일 입력 인풋, 비밀번호 입력 인풋, 로그인 버튼 배치
- 로그인 버튼 아래에 회원가입 페이지로 이동하는 링크도 배치
- 좌측 사이드바, 상단 헤더 컴포넌트는 보이지 않게 해줘

#회원가입 페이지

- 로고 텍스트, 이메일 입력 인풋, 비밀번호 입력 인풋, 비밀번호를 확인하는 인풋, 회원가입 버튼 배치
- 회원가입 버튼 아래에 로그인 페이지로 이동하는 링크 배치

# 주의 사항

- 아직 로그인, 회원가입 기능은 구현하지 마


===>localhost:3000/login ==>로그인 페이지 확인
===>localhost:3000/signup ==>회원가입 페이지 확인
===> 로그인 회원가입 페이지 구현 커밋

2. 회원가입 기능 구현
회원가입 기능을 구현해.

- 이메일, 비밀번호, 비밀번호 확인 모두 입력해야만 회원가입 버튼 클릭 가능
- 회원가입 버튼 클릭 시 비밀번호 일치 여부 확인
- 회원가입이 실패하면 한국말로 오류 메시지를 화면 중앙 상단에 토스트 메시지로 나타내줘
- 회원가입이 성공하면 인덱스 페이지로 이동


===> 토스트 메시지->경고창과 비슷한 기능

===>localhost:3000/signup ->실행
===>F12 관리자창=>network에서 확인
회원가입 실패=>비밀번호 1자리
회원가입 성공=>비밀번호 6자리

====>Response에서 확인
=====>성공하면 수파베이스에서 데이터 확인
======>인증->Users에서 최종 확인

=====>회원 가입 기능 구현 커밋


3. 로그인 기능 구현
로그인 기능을 구현해.

- 이메일, 비밀번호를 입력해야만 로그인 버튼 클릭 가능
- 로그인이 실패하면 한국말로 오류 메시지를 화면 상단에 토스트 메시지로 나타내줘
- 로그인이 성공하면 인덱스 페이지로 이동



===>localhost:3000/login 으로 학인
====>관리자 창 F12->network에서 확인
