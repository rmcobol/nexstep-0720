<<페이지 접근 제어,  로그아웃 구현하기 프롬프트>>


1. 페이지 접근 제한

페이지 접근 제한 기능을 구현해.

- 인덱스 페이지, 폴더별 페이지, 새 링크 페이지는 로그인한 사용자만 접근 가능

===>로그인 상태에서 
===>브라우저 관리자 창에서 Application->Cookie->쿠키 정보 클리어 하면
===>로그아웃되서 로그인 페이지로 이동됨

===>페이지 접근 제한 커밋


2. 로그아웃 기능

로그아웃 기능을 구현해줘.

- 로그아웃 버튼을 좌측 사이드바 컴포넌트 최하단에 배치해줘
- 로그아웃 버튼 클릭 시 로그아웃을 진행해줘

===> 로그인 후 ==>로그아웃 작업==>로그인 화면으로 이동
===> 관리자 창에서 쿠키가 제거 되는지 확인

===> 로그아웃 기능 커밋



3. 비밀번호 재설정 기능

비밀번호 리셋 기능을 구현해줘.

- 로그인 페이지에 회원가입 링크 상단에 비밀번호 찾기 페이지로 향하는 링크를 추가해줘
- 비밀번호 찾기 페이지에는 이메일 인풋, 비밀번호 리셋 링크 발송 버튼 배치
- 발송 버튼 클릭 시 비밀번호 리셋 링크를 사용자가 입력한 이메일로 발송
- 리셋 링크 클릭 시 비밀번호를 재설정하는 페이지로 이동

===>실질적인 본인 이메일로 회원 가입후
===>로그인 비밀번호 재설정버튼 클릭=>이메일에서 확인후 비밀번호 변경
===>최종 확인
===>수파베이스에서 확인 =>인증=>Emails=>Reset password 에서 확인
===>비밀번호 리셋 기능 구현 커밋
