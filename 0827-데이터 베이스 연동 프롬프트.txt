<<데이터 베이스 연동 기능 구현>>

1.(폴더 추가)
 폴더 추가 기능을 구현해.

- 사용자가 추가한 폴더를 Supabase folders 테이블에 추가해
- 폴더 추가 버튼의 중복 클릭을 막아서 여러 개의 폴더가 동시에 추가되지 않도록 해줘
- 좌측 사이드바에 folders 테이블에 저장된 폴더를 불러와서 나열해줘
- 이 외의 기능은 구현하지 마
- MCP를 활용해서 테이블 구조를 확인한 다음 작업해

==>좌측 메뉴에 폴더에 나오면 프롬프트에서 제거 해달라고 해야 함.
==> 폴더 추가 기능 데이터 베이스 연동

2.(폴더 수정)
폴더 이름을 수정하는 기능을 구현해.

- 폴더 이름 수정 시 folders 테이블에 수정된 이름 업데이트

==>폴더 수정 데이터베이스 연동 커밋

3.(폴더 삭제)
폴더 삭제 기능을 구현해.

- 폴더 삭제 시 folders 테이블에서 해당 폴더 데이터를 제거해

==> 폴더 삭제 데이터베이스 연동 커밋

4.(링크 추가)
링크 추가 기능을 구현해.

- 사용자가 새 링크를 추가하면, links 테이블에 보관해
- 새 링크 페이지의 추가(저장)버튼의 중복 클릭을 막아서, 여러개의 링크가 동시에 추가되지 않도록 해줘
- 새 링크 페이지의 폴더를 선택하는 셀렉트 박스에 현재 folders 테이블이 보관된 모든 폴더의 목록을 나열해
- 추가된 링크들을 인텍스 페이지나 폴더별 페이지에 불러와서 보여주는 기능도 추가해
-  이 외의 시키지 않은 기능까지는 굳이 구현하지마
- mcp를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해

==>링크 추가 데이터베이스 연동 커밋

5.(링크 수정)
링크 수정 기능을 구현해.

- 링크 수정시 변경된 정보들을 links 테이블에 업데이트 해줘
-  이 외의 시키지 않은 기능까지는 굳이 구현하지마
- mcp를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해

==>링크 수정 데이터베이스 연동 커밋

6.(링크 삭제)
링크 삭제 기능을 구현해.

- 링크 삭제 시 links 테이블에서 해당 링크 데이터를 제거해

==>링크 삭제 데이터베이스 연동 커밋
